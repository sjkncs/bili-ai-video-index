## 数据来源 · 计算方法 · 口径限制

**数据来源**：B 站公开接口 `x/polymer/web-space/seasons_archives_list`（按 mid + season_id 逐合集抓取，`page_size=100`）。

**计算方法**：先把两位 UP 的合集清单全部取出，再逐个合集抓分集；**分类归属按合集的原始名称显式映射**到本仓库的目录（不做关键词模糊匹配——首版脚本用模糊匹配时漏掉了一整届会议系列，48 集应为 96 集）。

**口径限制**
- **只做目录索引**，不含视频文件、字幕或讲义。
- **标题为 B 站原文**。B 站标题上限 80 字符，超长会被截断；本仓库**不补全、不猜测论文全名**。
- 抓取期间 B 站会返回风控码 `-352`；本仓库的数据是在退避重试后取齐的，但**不保证与线上实时一致**。
- 「按类型」分目录的依据是**合集名称**，不是对内容的人工判定。机器之心的合集跨越"技术实践"与"产业"边界时，归类可能与你的直觉不同。
